### Otázka (Front)

Describe the Ethereum virtual machine (EVM).

### Odpověď (Back)

Ethereum virtual machine (EVM) is a transaction-based virtual machine that uses the Harvard architecture and runs Ethereum. Valid transactions transition the EVM from one state to another. The EVM consists of the following memory components:

- **stack** - facilitates the execution of bytecode,

- **calldata** - read-only storage that stores inputs of functions,

- **return data** - stores the outputs of functions,

- **memory** - volatile storage that is erased after function execution terminates,

- **storage** - persistent storage that can be used to store the state of a smart contract,

- **transient storage** - similar to storage but scoped to the current transaction.
