### Otázka (Front)

Describe Ethereum smart contracts.

### Odpověď (Back)

Ethereum smart contracts are automatic programs that can store data and run on the Ethereum Virtual Machine (EVM). They are deployed to the blockchain using transactions. This process creates a special account that can be used to interact with the deployed smart contract. Ethereum smart contracts have the following properties:

- **self-enforcing** - smart contracts are distributed across the nodes of the blockchain and require no central validation authority;

- **unstoppable** - smart contracts are irreversible, irrevocable, and their code can't be changed.
