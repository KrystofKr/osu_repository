### Otázka (Front)

Describe the properties of the Ethereum blockchain.

### Odpověď (Back)

The properties of the Ethereum blockchain are as follows:

- **peer-to-peer** - the blockchain is governed by a majority of nodes that communicate without a central authority;

- **distributed ledger** - the list of transactions is distributed across all nodes of the blockchain;

- **immutability** (append-only) - blocks cannot be changed retroactively because all the subsequent blocks would have to change as well;

- **cryptographically secure** - blocks are linked together using hashes;

- **updatable only with consensus** - nodes achieve consensus using a proof of stake system.
