### Otázka (Front)

Describe the order of volatility.

### Odpověď (Back)

Order of volatility is defined in RFC 3227 and conveys the idea that data acquisition should progress from the most volatile to the least volatile evidence sources. An example order of volatility may look as follows:

- registers and caches;
- operating memory;
- temporary file systems;
- disks;
- archival media.

### Otázka (Front)

Describe the properties of digital evidence.

### Odpověď (Back)

The properties of digital evidence are as follows:

- **immateriality** - data is intangible, but requires tangible storage;

- **latency** - data cannot be seen, can be hidden, or encrypted;

- **temporal identifiability** - data is often created with a timestamp;
- **high information content** - data can contain a large amount of information in comparison to other evidence types;
- **problematic durability** - storage of the data can deteriorate;

- **low information density** - only a small fragment of the data can be relevant;

- **heterogenity** - data comes in various forms and versions on differing platforms and media;

- **geographical scope **- data can be stored anywhere, which is problematic in terms of jurisdiction,

- **access protection** - data can be protected from unauthorized access;

- **automated processing** - data can share a structure which enables automated analysis;

- **restorability** - intentionally destroyed data can often be restored;

- **difficult to present** - data can be difficult to interpret without specialized knowlege.

### Otázka (Front)

What is a disk image?

### Odpověď (Back)

A disk image is a file or a set of files that captures a snapshot of the content and structure of a memory device. Traditionally, disk images were taken as bit-by-bit copies; however, compression and deduplication is commonly used to reduce the size of the file set.

### Otázka (Front)

Describe the diferences between a raw disk image and a forensic disk image format.

### Odpověď (Back)

A raw disk image represents the data as-is and has the advantage of portability. In constrast, forensic disk images usually contain metadata, have built-in integrity verification (such as checksums), and often leverage compression.

### Otázka (Front)

Describe the difference between dead and live forensic imaging.

### Odpověď (Back)

**Dead forensic imaging** refers to the process of creating a forensic image of a memory device that is either powered off or attached through a write-blocker. **Live forensic imaging** takes place on a running system and has the advantage of capturing its volatile memory as well. However, this approach has a higher risk of data alteration.
