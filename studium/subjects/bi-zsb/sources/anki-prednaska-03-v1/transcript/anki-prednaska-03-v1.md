Describe the incident response process.

### Odpověď (Back)

The incident response process entails the following phases:

- **preparation** - establish an incident response plan and team;

- **detection and analysis** - threat intelligence, threat hunting, proactive alerts;

- **containment, eradication, and recovery** - stop the spread, patch vulnerabilities, restore normal operations;

- **post-incident activity** - update incident response plans, harden environment.

### Otázka (Front)

What is the OODA loop?

### Odpověď (Back)

The OODA loop is a decision-making approach that focuses on filtering available information, putting it in context and taking appropriate action while adapting as more data becomes available. It consists of the following phases:

- observe,

- orient,

- decide,

- act.
