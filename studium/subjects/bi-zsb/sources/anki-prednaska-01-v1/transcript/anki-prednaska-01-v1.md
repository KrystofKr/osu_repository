### Otázka (Front)

What is defense-in-depth (layered security)?

### Odpověď (Back)

Defense-in depth (layered security) is a princip which entails designing security measures in a way that they form several layers of mutually redundant defenses. This means that if an attacker manages to breach a single layer, they still have a number of them left, which heightens the technological and temporal difficulty of the attack and provides the defenders with more time to discover and deflect such attack.

### Otázka (Front)

List Saltzer and Schroeder's design principles for secure software systems design.

### Odpověď (Back)

Saltzer and Schroeder's design principles include:

- **economy of mechanism** - keep the design as simple and small as possible,

- **fail-safe defaults** - base access decisions on permission rather than exclusion,

- **complete mediation** - every access to every object must be authorized,

- **open design** - the design should not be secret,

- **separation of privilege** - do not rely on a single subject for authorization,

- **least privilege** - every program and user should operate using the smallest set of privileges they require,

- **least common mechanism** - minimize mechanisms common for more than one user,

- **psychological acceptability** - design with ease of use in mind,
and others.

### Otázka (Front)

Describe the concept of an adequately secure system.

### Odpověď (Back)

According to NIST, for a system to be adequately secure, it needs to:

- meet minimum tolerable levels of security, as determined by experience, analysis, or a combination of both;
- be as secure as resonably practicable (ASARP).

### Otázka (Front)

What is system security engineering?

### Odpověď (Back)

System security engineering is a discipline focusing on designing and developing secure and dependable systems. It usually entails the following phases:

- construction of a threat model,
- establishment of a security policy,
- implementation,
- assurance.
