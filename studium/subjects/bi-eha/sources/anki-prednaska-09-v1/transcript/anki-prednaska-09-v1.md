### Otázka (Front)

Describe the methodology used for testing Server Message Block (SMB).

### Odpověď (Back)

Testing SMB usually follows these steps:

- **reconnaissance** - gather information about the SMB implementation;

- **enumeration** - identify SMB-related services and potential attack vectors such as unnecessary SMB shares;

- **exploitation **and **privilege escalation** - test for insecure permissions, weak authentication, or unpatched SMB implementations;
- **lateral movement **and **persistance** - search for other vulnerable SMB-enabled systems and create backdoors.
