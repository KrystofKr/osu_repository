- **vlnová délka **(\(\lambda\)) - vzdálenost dvou bodů kmitajících ve fázi,

- **frekvence **(\(f\)) - počet opakování periody za jednotku času,

- **amplituda **- maximální hodnota vlny,

přičemž platí

\[f = \frac c \lambda,\]kde \(c\) je rychlost světla.

Popište request to send / clear to send (RTS/CTS) mechanismus.

### Odpověď (Back)

Request to send / clear to send (RTS/CTS) je mechanismus, se kterým se často kombinuje CSMA/CA v 802.11 sítích za účelem snížení počtu kolizí způsobovaných problémem skrytého uzlu. Funguje následovně:

- stanice, která chce odvysílat data pošle AP rámec RTS;
- pokud žádná jiná stanice dříve nežádala o vysílání, odpoví AP stanici rámcem CTS;
- CTS však obdrží všechny stanice, které jsou k AP připojeny;
- stanice, pro kterou byl CTS určen začne vysílat a ostaní stanice čekají náhodnou dobu.
